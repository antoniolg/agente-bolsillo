# Agente bolsillo

Ejercicio paso a paso para la charla **Un agente en tu bolsillo**.

La historia del repo se construye commit a commit. Cada commit añade una pieza del arnés.

## Paso 1

Bot mínimo con Pi:

- Telegram recibe el mensaje.
- Pi ejecuta el turno.
- El bot responde.

## Comandos

```bash
pnpm install
cp .env.example .env
pnpm bot
```
